# Cburnett chess pieces

The chess-piece images displayed by this project are Lichess's `cburnett`
piece set by Colin M.L. Burnett. Lichess identifies the set as
GPL-2.0-or-later.

- Source: https://github.com/lichess-org/lila/tree/master/public/piece/cburnett
- Attribution: https://github.com/lichess-org/lila/blob/master/COPYING.md
- License: https://www.gnu.org/licenses/old-licenses/gpl-2.0.txt

The unmodified SVG files used by the application are bundled in
`assets/pieces/`. The deployed game does not request them from Lichess's asset
host at runtime.
